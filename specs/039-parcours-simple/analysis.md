# Analyse de cohérence

La zone existante reste la source du calcul et la sauvegarde réutilise le format version 6. Le calcul existant prend en compte une part PMR modifiable dans les outils détaillés sans la demander dans le parcours simple. Les étapes 3 à 7 sont hors périmètre ; aucune donnée de trafic réelle ni conformité ne sont déduites. Le résultat est théorique et la forme du terrain peut réduire la capacité.
